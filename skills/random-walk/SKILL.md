# 随机漫步 🎲

从卡片笔记库中随机抽取卡片，帮助用户重新发现被遗忘的想法、建立意想不到的连接。

## 触发条件

当用户说「随机漫步」时触发此 skill。

## 配置

在使用前，需要在 `TOOLS.md` 或 skill 配置中设置卡片路径：

```yaml
random-walk:
  cards_path: "/path/to/your/ObsidianVault/Cards"  # 你的卡片笔记目录
```

如果未配置，首次触发时询问用户卡片目录路径。

## 流程

### Step 1: 检查配置

首次使用时，检查是否已配置 `cards_path`：
- 如果已配置，直接进入 Step 2
- 如果未配置，询问用户：「请告诉我你的卡片笔记目录路径（例如 `/home/user/ObsidianVault/Cards`）」

### Step 2: 展示菜单

当用户说「随机漫步」时，展示以下选项：

```
🎲 随机漫步 — 选择你的玩法：

1️⃣ **纯随机** — 随便抽一张，看看命运给你什么
2️⃣ **主题随机** — 在某个 tag 范围内随机
3️⃣ **关联漫步** — 从一张卡片出发，沿着双向链接随机游走
4️⃣ **时间加权** — 优先抽取很久没看过的卡片（按文件修改时间）
5️⃣ **组合碰撞** — 随机抽 2-3 张，看看能不能产生新想法

输入数字选择，或直接说你想要的玩法。
```

### Step 3: 执行抽取

根据用户选择执行对应逻辑（以下 `$CARDS_PATH` 为配置的卡片目录）：

#### 1️⃣ 纯随机

```bash
# 获取所有卡片并随机选一张
ls "$CARDS_PATH"/*.md | shuf -n 1
```

#### 2️⃣ 主题随机

1. 先列出可用的 tags：
```bash
# 提取所有 tags（适配 YAML frontmatter 和行内 tag 格式）
grep -rh "^- " "$CARDS_PATH"/*.md | grep -v "^\- \[\[" | sed 's/^- //' | sort | uniq -c | sort -rn
```

2. 让用户选择一个 tag

3. 在该 tag 范围内随机：
```bash
# 找到包含指定 tag 的卡片并随机选一张
grep -l "^- $TAG" "$CARDS_PATH"/*.md | shuf -n 1
```

#### 3️⃣ 关联漫步

1. 先随机选一张有双向链接的卡片作为起点：
```bash
grep -l "\[\[" "$CARDS_PATH"/*.md | shuf -n 1
```

2. 读取卡片内容，提取双向链接：
```bash
grep -o "\[\[[^]]*\]\]" "$CARD_FILE" | sed 's/\[\[//g; s/\]\]//g'
```

3. 从链接中随机选一个，跳转到那张卡片

4. 询问用户是否继续漫步，或停在当前卡片

#### 4️⃣ 时间加权

```bash
# 按修改时间排序，取最旧的 20% 卡片，然后随机选一张
ls -t "$CARDS_PATH"/*.md | tail -n $(( $(ls "$CARDS_PATH"/*.md | wc -l) / 5 )) | shuf -n 1
```

#### 5️⃣ 组合碰撞

```bash
# 随机抽 2-3 张卡片
ls "$CARDS_PATH"/*.md | shuf -n 3
```

展示所有卡片的核心内容，然后问用户：「这几张卡片之间有什么联系？能碰撞出什么新想法？」

### Step 4: 展示卡片 & 提问

抽到卡片后：

1. **展示卡片内容**（完整或摘要，取决于长度）

2. **基于卡片内容提一个问题**，引导用户思考。问题类型：
   - 这个想法现在还成立吗？
   - 这和你最近在做的事有什么关联？
   - 如果要把这个想法付诸实践，第一步是什么？
   - 这张卡片让你想到了什么？
   - 有没有什么新的理解或补充？

3. **可选后续动作**：
   - 继续漫步（再抽一张）
   - 编辑这张卡片
   - 查看相关卡片（如果有双向链接）

## 卡片格式兼容

支持以下常见的 Obsidian 卡片格式：

**命名格式：**
- `YYYYMMDD-标题.md`（推荐）
- `标题.md`
- 任意 `.md` 文件

**Tag 格式：**
- YAML frontmatter: `tags: [tag1, tag2]` 或 `tags:\n  - tag1\n  - tag2`
- 行内 tag: `#tag1 #tag2`

**双向链接：**
- `[[卡片名称]]`
- `[[卡片名称|显示文本]]`

## 安装

1. 将此 skill 放入你的 skills 目录
2. 在 `TOOLS.md` 中配置卡片路径：
   ```yaml
   random-walk:
     cards_path: "/your/path/to/Cards"
   ```
3. 对 Agent 说「随机漫步」即可开始
